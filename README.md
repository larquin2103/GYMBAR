# GYMBAR

Plataforma SaaS profesional para la administración integral de gimnasios.

Diseñada para sentirse tan rápida y clara como Linear, Stripe Dashboard y Notion:
operable sin capacitación, cada acción importante en menos de 15 segundos.

## Estado actual

**Fase de diseño previa al código.** Todo el paquete de arquitectura y diseño
está en [`/docs`](./docs/README.md). No se escribe código de aplicación sin la
arquitectura correspondiente aprobada.

👉 Empieza por [`docs/README.md`](./docs/README.md).
